Echo Notes — 三种前端方向交互原型
版本：方向评审稿 · 2026-11-08

开始体验
1. 双击 Echo-Notes-ABC-Compare.html，在桌面浏览器打开。
2. 点击 A、B、C 切换方向。可切换桌面/窄屏、浅色/深色，以及展开画面。
3. 每个方向都可独立打开，不需要联网、安装依赖或启动服务。

方向区别
A — 日历索引与原生笔记：灰紫色、Obsidian 分栏；左侧筛选，中间会议摘要，右侧模拟原生笔记叶子。
B — 日期阅读器与内嵌详情：浅蓝与靛色、留白阅读；日期与筛选置顶，会议详情在主工作区内切换。
C — 项目工作台与讨论时间线：暖灰与森林绿；项目背景、历史讨论、已保存问题并列组织。

建议体验同一组任务
- 找到 11 月 7 日参加的会议，筛选“订单履约优化”。
- 阅读“订单履约 · 异常处理评审”，查看原话、项目及记忆入口。
- 打开“为什么把统一提醒调整为分级处理？”，增减素材，查看上下文与历史标记。
- 查看日期待补全及未关联项目的会议如何保留。
- 体验 Agent 连接流程，比较独立维护入口是否清楚。

数据与功能边界
全部内容均为构造的演示数据：10 场会议、3 个项目、3 个问题。页面不读取真实 Vault，不调用模型，不安装 Skill，不连接真实 Agent。
“原生笔记”是在 HTML 内模拟的笔记叶子，不是已经嵌入 Obsidian 的生产插件。
数据调整及模拟连接只作用于演示页面。选材、Markdown 内容生成、复制或下载入口均是本地浏览器交互。
下载功能使用 Blob；浏览器预览容器可能限制下载，建议下载 HTML 后在本机浏览器打开。共享预览环境中已验证 Markdown 内容，但未观察到浏览器下载事件，因此不将文件落盘标记为已验证。
“选择此方向”记录的是方向偏好，不代表批准生产实现。

已核验

- A 的日期/项目筛选、日期待补全、材料选择、笔记详情与返回。
- B 的原文阅读、问题选择—选材—核验—Markdown 预览、窄屏详情与返回。
- C 的项目/未关联/日期待补全、已保存问题和素材预览、Agent 模拟连接。
- 移动端 C 侧栏关闭后退出辅助技术树。
- 四个 HTML 的 JavaScript 语法、静态重复 ID、外链资源检查。
